Estudaê — Sistema de gerenciamento de tarefas acadêmicas

Estou muito feliz em compartilhar o projeto Estudaê, uma aplicação desenvolvida para ajudar estudantes a organizarem tarefas, prazos e compromissos acadêmicos.

A ideia do projeto foi unir conceitos de frontend, backend, banco de dados e CRUD em uma solução completa, com foco em portfólio e desenvolvimento prático.

Tecnologias utilizadas:
- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- HTML
- CSS
- JavaScript
- API REST
- Swagger/OpenAPI

Principais funcionalidades:
- cadastro e login de usuário
- criação, edição e exclusão de tarefas
- marcação de tarefas como concluídas
- definição de data de entrega
- categorias de tarefas
- dashboard com métricas gerais
- filtros por status e categoria

Esse projeto foi importante para reforçar meu conhecimento em desenvolvimento full stack e em arquitetura de software, além de mostrar como integrar diferentes camadas de uma aplicação: interface, lógica de negócio, persistência e API.

Estou em constante evolução e projetos como esse me ajudam a consolidar conceitos importantes para minha jornada em tecnologia.
