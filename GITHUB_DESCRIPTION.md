## Estudaê

Sistema de gerenciamento de tarefas acadêmicas desenvolvido com Java, Spring Boot, PostgreSQL, HTML, CSS e JavaScript.

### Objetivo

O projeto tem como objetivo ajudar estudantes a organizarem tarefas, prazos e atividades acadêmicas em um único lugar, com foco em produtividade e organização pessoal.

### Funcionalidades

- Cadastro e login de usuário
- CRUD completo de tarefas
- Categorias de tarefas
- Data de entrega
- Dashboard com métricas
- Filtros por status e categoria
- API REST

### Stack

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- HTML
- CSS
- JavaScript
- Swagger/OpenAPI

### Status

Projeto em desenvolvimento com foco em portfólio e apresentação profissional.
